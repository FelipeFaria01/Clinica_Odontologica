# 🦷 Clínica Odontológica | Full Stack

Aplicação web Full Stack desenvolvida para uma clínica odontológica, com o objetivo de oferecer uma presença digital moderna, facilitar o acesso às informações sobre os serviços e proporcionar uma experiência intuitiva aos pacientes.

O projeto contempla uma interface responsiva, integração entre frontend e backend, consumo de API REST e funcionalidades de contato.

## 🎯 Objetivo do projeto

Desenvolver uma solução web que simule as necessidades reais de uma clínica odontológica, aplicando conceitos de desenvolvimento Full Stack, organização de código, responsividade e comunicação entre cliente e servidor.

O projeto também foi desenvolvido para consolidar conhecimentos técnicos e demonstrar habilidades práticas em desenvolvimento web.

## 🚀 Funcionalidades

- Interface moderna e responsiva.
- Apresentação institucional da clínica odontológica.
- Exibição de informações sobre serviços.
- Formulário de contato com validação.
- Integração entre frontend e backend.
- Comunicação com API REST.
- Integração com WhatsApp para facilitar o contato.
- Publicação da aplicação em ambiente web.

## 🛠️ Tecnologias utilizadas

### Frontend

### Backend

## ⚙️ Como executar o projeto

### 1. Clonar o repositório

```bash
git clone https://github.com/FelipeFaria01/Clinica_Odontologica.git
cd Clinica_Odontologica
```

### 2. Instalar e iniciar o frontend

```bash
cd frontend
npm install
npm run dev
```

### 3. Instalar e iniciar o backend

Em outro terminal:

```bash
cd backend
npm install
npm run dev
```

**Observação:** configure as variáveis de ambiente necessárias antes de executar o projeto. Os comandos de inicialização devem corresponder aos scripts definidos nos arquivos `package.json`.
